# Мир открытий — браузерная версия 1.0

## Быстрый запуск
- Для обычного браузера скачайте `mir_otkrytiy_browser.html` и откройте файл в Chrome, Edge, Firefox или Safari. Это самостоятельный файл: интернет и установка не требуются.
- Если браузер запрещает локальное сохранение файлов, откройте приложение через локальный веб-сервер или HTTPS-сайт.
- Для установки на главный экран iPhone и офлайн-кэша используйте папку `mir_otkrytiy` на HTTPS-хостинге. Откройте адрес в Safari → «Поделиться» → «На экран Домой».

## Что внутри
- Два независимых профиля: Регина (6 лет) и Каролина (4 года).
- Пять миров: математика, буквы, логика, память и творчество.
- Пять заданий в каждом мире для каждого возраста: всего 50 заданий.
- Случайный порядок заданий, проверка ответов и подсказка правильного варианта.
- Звёзды начисляются за новый лучший результат, поэтому повторное прохождение не позволяет бесконечно накручивать награды.
- Родительская статистика с отдельным сбросом прогресса каждого ребёнка. Вход в неё закрыт простым вопросом для взрослых, это не полноценная защита PIN-кодом.
- Прогресс сохраняется локально в браузере на конкретном устройстве. Облачной синхронизации между устройствами нет.

## Состав папки PWA
- `index.html` — приложение.
- `manifest.webmanifest` — параметры установки.
- `sw.js` — офлайн-кэш.
- `icon-180.png`, `icon-512.png` — иконки.

## Важно
Standalone HTML можно открыть в браузере как файл. Для установки PWA на iPhone, корректной работы service worker и одной постоянной публичной ссылки нужен HTTPS-хостинг. Архив сам по себе не публикует сайт в интернете.
